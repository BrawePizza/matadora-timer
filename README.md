# 🍅 Pomodoro — Таймер «Помодоро»

Курсовой проект: веб-приложение таймера, работающего по технике Pomodoro.
## 🖥️ Демо

[https://lsb.ink/matadora/](https://lsb.ink/matadora/)

## 📖 Описание

Техника Pomodoro разбивает работу на интервалы (обычно 25 минут) и чередует их с короткими перерывами. После 4 «помидоров» наступает длинный перерыв (15 минут).

Это приложение позволяет:

- Запускать таймер на 25 минут работы и автоматически переключаться на отдых (5 минут)
- Видеть, сколько времени осталось
- Получать звуковой сигнал и всплывающее уведомление при смене режима
- Настроить длительность интервалов и количество помидоров до длинного перерыва
- Просматривать статистику: количество завершённых помидоров и общее время работы
- Историю завершённых сессий
- Экспорт статистики в JSON или CSV

## 🚀 Как запустить

1. Установите Node.js: https://nodejs.org/

2. Установите зависимости:
```bash
npm install
```

4. Запустите проект:
```bash
npm start
```

5. Откройте:
```bash
http://127.0.0.1:XXXX (Адрес и порт указаны в консоли)
```

## ⚙️ Функционал

| Раздел | Описание |
|--------|----------|
| Таймер | 25/5 минут, старт/пауза/сброс |
| Звук | Сигнал при смене режима |
| Уведомления | Popup при переключении |
| Статистика | Счёт помидоров и времени |
| История | localStorage список сессий |
| Настройки | Время и циклы |
| Экспорт | JSON / CSV |
