**🍅 Pomodoro Pro — Таймер "Помодоро"**  
Курсовой проект: веб-приложение таймера, работающего по технике Pomodoro.  
**Описание**  
Техника Pomodoro разбивает работу на интервалы (обычно 25 минут) и чередует их с короткими перерывами. После 4-х «помидоров» наступает длинный перерыв (15 минут).  
Это приложение позволяет:  
- Запускать таймер на 25 минут работы, затем автоматически направлять на отдых (5 минут).  
- Видеть, сколько времени осталось.  
- Получать звуковой сигнал и всплывающее уведомление при смене режима.  
- Настраивать длительность интервалов, количество помидоров до длинного перерыва.  
- Просматривать статистику: сколько помидоров завершено и общее время работы.  
- Смотреть историю завершённых сессий.  
- Экспортировать статистику в формате JSON или CSV для дальнейшего анализа.  
**Как запустить**  
1. Убедитесь, что на компьютере установлен [**Node.js**.](https://nodejs.org/ "https://nodejs.org/")  
2. Откройте терминал в папке с проектом и установите зависимости:  
npm install  
   
1. Запустите локальный сервер:  
npm start  
   
1. Откройте в браузере адрес **http://127.0.0.1:8080** (или тот, который появится в терминале).  
2.    
**Функционал**  
| | |  
|-|-|  
| **Раздел** | **Что делает** |   
| **Таймер** | Отсчитывает 25 мин работы и 5 мин отдыха. Кнопки: Старт/Пауза, Сброс. |   
| **Звуковой сигнал** | При завершении таймера звучит мелодия. |   
| **Уведомления** | При смене режима показывается всплывающее сообщение на экране. |   
| **Статистика** | Подсчёт количества помидоров и общего времени работы (цифры сохраняются при перезагрузке). |   
| **История** | Список завершённых помидоров с указанием времени и длительности (хранится в localStorage). |   
| **Настройки** | Можно установить: длительность работы, короткого отдыха, длинного перерыва и число помидоров до длинного перерыва. Настройки сохраняются. |   
| **Экспорт** | Кнопки JSON и CSV скачивают файл со статистикой и историей. |

| | |  
|-|-|
